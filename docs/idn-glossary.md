# Glosarium Terjemahan EN→ID

Acuan konsistensi saat mengganti copy UI ke Bahasa Indonesia. Prinsip:
aksi/navigasi diterjemahkan, istilah finansial teknis tetap English
(market cap, P/E, momentum, screener, MSCI, EMA), simbol/ticker/company
name tetap asli.

| English | Indonesia |
|---|---|

| Edit Watchlist | Ubah Daftar Pantauan |
| Trending | Tren |
| Highlights | Sorotan |
| Install App | Pasang Aplikasi |

| Cancel | Batal |
